جرد الذهب — حزمة النشر
=======================

الملفات
- index.html : المنصة كاملة (ملف واحد). ارفعه على أي استضافة ثابتة (Netlify / Vercel / GitHub Pages / Cloudflare Pages).
- jard-print-bridge.py : وسيط الطباعة المحلي (اختياري) للطباعة الصامتة عبر شبكة IP أو طابعة USB النظامية.

1) تفعيل تسجيل الدخول برقم الجوال (مرة واحدة، من لوحة Supabase)
- مشروع Supabase المخصص: jard-gold  (المعرّف ttycfyzvqabsspcghkuf)
- افتح: Authentication ← Providers ← Phone ← فعّل Phone ثم اختر مزوّد الرسائل (Twilio أو MessageBird أو Vonage أو Textlocal) وأدخل بياناته.
- لأرقام السعودية يمكن استخدام مزوّد محلي عبر "Send SMS Hook".
- للتجربة دون رسائل: في نفس الصفحة أضف "Test Phone Numbers and OTPs".
- جدول البيانات جاهز ومعزول لكل رقم جوال بسياسات RLS، ويحتفظ بآخر 30 نسخة تاريخية تلقائيًا.

2) الدخول والمزامنة
- أول مرة: رقم الجوال ← رمز التحقق ← تعيين كلمة مرور. لاحقًا: الدخول بكلمة المرور.
- المزامنة تلقائية بين الأجهزة، وتعمل دون اتصال وتُرفع لاحقًا. عند التعارض تُعرض نافذة للاختيار.
- لا يعمل الدخول داخل معاينة claude.ai، افتح الرابط المنشور على استضافتك.

3) الطباعة المباشرة (الإعدادات ← الطابعة)
- الأفضل استقرارًا وسرعة: شبكة IP بكابل LAN أو USB. البلوتوث الأضعف.
- شبكة IP أو طابعة USB النظامية: شغّل على جهاز الكاشير:  python jard-print-bridge.py
  ثم اختر الطريقة في الإعدادات وأدخل IP الطابعة (المنفذ 9100) واضغط «فحص الوسيط» ثم «طباعة تجريبية».
- USB مباشر وبلوتوث وتسلسلي تعمل من Chrome/Edge دون وسيط (حسب الجهاز).
- إن خرج الملصق بخلفية سوداء فعّل «عكس الألوان»، وراجع لغة الطابعة (TSPL / ZPL / ESC/POS).

4) التكامل (الإعدادات ← التكامل والمتجر)
- Webhook تلقائي بصيغة JSON موقَّعة (HMAC-SHA256) لكل عملية، مع إعادة محاولة عند انقطاع الاتصال.
- تصدير قيود يومية وفواتير ومصروفات وJSON كامل، وملفات منتجات Shopify وWooCommerce.
